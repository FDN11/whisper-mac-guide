# Whisper на Mac: расшифровка аудио и видео в текст

Whisper — бесплатная программа, которая превращает речь из аудио или видео в текст прямо на вашем компьютере, без интернета и без загрузки файлов куда-либо. Настройка — один раз минут на 15–30 (больше всего времени уходит на скачивание), дальше одна команда на каждый файл.

Инструкция для Mac на чипе Apple M1 и новее (M2, M3, M4, M5): меню  → «Об этом Mac» → строка «Чип». На Mac с Intel всё тоже заработает, но расшифровка будет в несколько раз медленнее, а в шаге 1 вместо `/opt/homebrew` нужно писать `/usr/local`.

## Как работать с Терминалом

- Открыть: Cmd + Пробел → набрать «Терминал» → Enter.
- Команды из этой инструкции копируйте целиком (каждый серый блок) и вставляйте в Терминал через Cmd + V, затем Enter.
- Пока команда работает, Терминал не принимает новые. Готово, когда снова появилась строка с вашим именем и знаком `%` в конце.
- Если Терминал просит пароль — это пароль от входа в Mac. При вводе символы не отображаются, это нормально: наберите и нажмите Enter.
- **Путь к файлу не нужно печатать вручную:** перетащите файл из Finder мышкой прямо в окно Терминала — путь вставится сам.

## Шаг 1. Установить Homebrew (один раз)

Homebrew — «магазин приложений» для Терминала, через него ставятся Whisper и конвертер звука.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Установка спросит пароль от Mac и попросит нажать Enter. В конце появится блок «Next steps» — выполните эту команду, чтобы Терминал «увидел» Homebrew:

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
```

Проверка — должна появиться версия, а не ошибка:

```bash
brew --version
```

## Шаг 2. Установить Whisper и конвертер звука (один раз)

`whisper-cpp` — сама расшифровка, быстрая версия, которая использует видеокарту Mac. `ffmpeg` — достаёт звук из видео и переводит любой формат (mp3, m4a, ogg, mp4, mov, голосовые из Telegram и WhatsApp) в нужный Whisper.

```bash
brew install whisper-cpp ffmpeg
```

## Шаг 3. Скачать модель (один раз)

Модель — это «мозг» Whisper, отдельный большой файл. Сначала создаём для моделей папку:

```bash
mkdir -p ~/whisper-models
```

Затем скачиваем основную модель — **large-v3** (3 ГБ, лучшее качество для русского):

```bash
curl -L -o ~/whisper-models/ggml-large-v3.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin
```

### Чем отличаются модели

| Модель | Размер | Скорость | Качество русского | Когда брать |
|---|---|---|---|---|
| tiny | 75 МБ | очень быстро | плохо | только проверить, что всё работает |
| base | 142 МБ | очень быстро | слабо, много ошибок | черновик чистой речи |
| small | 466 МБ | быстро | средне | старый или слабый Mac |
| medium | 1,5 ГБ | средне | хорошо | компромисс скорости и качества |
| large-v3-turbo | 1,6 ГБ | быстро | очень хорошо | когда нужно быстрее и качество чуть ниже не критично |
| **large-v3** | **3 ГБ** | **медленнее turbo в 3–5 раз** | **лучшее** | **основной вариант** |

Модели с `.en` в названии понимают только английский — для русского их не берите.

Скачать другую модель — та же команда, поменяйте название в двух местах. Например, быстрая large-v3-turbo:

```bash
curl -L -o ~/whisper-models/ggml-large-v3-turbo.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

Посмотреть, какие модели уже скачаны:

```bash
ls -lh ~/whisper-models
```

## Шаг 4. Создать короткую команду transcribe (один раз)

Эта команда добавляет в Терминал слово `transcribe`, которое делает всё сразу: достаёт звук, расшифровывает и сохраняет текст рядом с исходным файлом. Скопируйте блок целиком:

```bash
cat >> ~/.zshrc <<'EOF'
transcribe() {
  local model="${WHISPER_MODEL:-$HOME/whisper-models/ggml-large-v3.bin}"
  local f base tmp
  [ -f "$model" ] || { echo "✖ Нет модели: $model — скачайте её (шаг 3)"; return 1; }
  for f in "$@"; do
    base="${f%.*}"; tmp="${TMPDIR:-/tmp}/whisper_$$.wav"
    echo "▶ $f"
    ffmpeg -loglevel error -y -i "$f" -ar 16000 -ac 1 -c:a pcm_s16le "$tmp" &&
    whisper-cli -m "$model" -l "${WHISPER_LANG:-ru}" -otxt -osrt -of "$base" "$tmp" >/dev/null 2>&1 &&
    echo "✔ Готово: $base.txt" || echo "✖ Не получилось расшифровать: $f"
    rm -f "$tmp"
  done
}
EOF
source ~/.zshrc
```

Настройка закончена. Дальше — только шаг 5.

## Шаг 5. Расшифровать файл (каждый раз)

1. Откройте Терминал.
2. Напечатайте `transcribe` и **пробел**.
3. Перетащите файл из Finder в окно Терминала.
4. Нажмите Enter.

В итоге строка выглядит примерно так:

```bash
transcribe /Users/имя/Downloads/встреча.mp4
```

Рядом с исходным файлом появятся два файла с тем же названием:

- `встреча.txt` — сплошной текст;
- `встреча.srt` — текст с таймкодами (видно, на какой минуте что сказано; открывается любым текстовым редактором, подходит как субтитры к видео).

Ориентир по времени на Mac с чипом M1 и новее: часовая запись с моделью large-v3 — порядка 10–20 минут, с turbo — в несколько раз быстрее.

### Готовые шаблоны

Несколько файлов за раз — перетащите их все после слова `transcribe`:

```bash
transcribe ФАЙЛ1 ФАЙЛ2 ФАЙЛ3
```

Все mp3 из папки «Загрузки»:

```bash
transcribe ~/Downloads/*.mp3
```

Все файлы из отдельной папки — например, заведите на рабочем столе папку «Расшифровать» и складывайте туда записи:

```bash
mkdir -p ~/Desktop/Расшифровать
```

```bash
transcribe ~/Desktop/Расшифровать/*.*
```

Запись на английском (или `auto` — Whisper определит язык сам):

```bash
WHISPER_LANG=en transcribe ФАЙЛ
```

Нужно быстрее — модель turbo (сначала скачайте её, шаг 3):

```bash
WHISPER_MODEL=~/whisper-models/ggml-large-v3-turbo.bin transcribe ФАЙЛ
```

Открыть получившийся текст:

```bash
open ~/Downloads/встреча.txt
```

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `command not found: brew` | Не выполнена вторая команда из шага 1. Выполните её и закройте/откройте Терминал. |
| `command not found: transcribe` | Закройте Терминал и откройте заново, или выполните `source ~/.zshrc`. |
| Строка `▶` появилась, а `✔ Готово` — нет | Проверьте, что модель скачана: `ls -lh ~/whisper-models` — файл должен весить сотни мегабайт или гигабайты. Если 0 байт или его нет — повторите шаг 3. |
| `✖ Нет модели` | Команда ищет модель large-v3. Скачайте её (шаг 3) или запускайте с той, что уже скачана: `WHISPER_MODEL=~/whisper-models/ИМЯ.bin transcribe ФАЙЛ`. |
| `No such file or directory` | В пути ошибка. Сотрите путь и перетащите файл мышкой ещё раз. |
| Текст с ошибками | Сильно помогает чистый звук без музыки и шума. Если стоит turbo — вернитесь на large-v3. |
| В тексте повторяется одна и та же фраза или «Продолжение следует…» | Так Whisper «додумывает» тишину в конце записи — просто удалите эти строки. |

Ничего никуда не отправляется: и модели, и расшифровка работают только на этом Mac, поэтому подходит и для конфиденциальных записей.
